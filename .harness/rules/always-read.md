# my.harnessのルール

このリポジトリだけで守るルールである。中身は`CONTRIBUTING.md`に書き、ここでは場所だけを指す。

- ファイルを変える前に、`CONTRIBUTING.md`を読む。
- 質問に答える前に、`CONTRIBUTING.md`の節「答えと変更で見る範囲」を読む。
- 変えたら、`tests/run-test-suite.sh`を動かし、出力を示す。何を確かめるかは、`CONTRIBUTING.md`の節「機械で確かめるもの」に書く。
- レビュー役の組み合わせは、`CONTRIBUTING.md`の節「レビュー役の組み合わせ」のとおりにする。
- 残した指摘は、PRの本文に書かず、`CONTRIBUTING.md`の節「残した指摘の形」のとおりにする。
