# 不具合の修正

誤った動きを直す変更で、変更の記録に書くことである。本番の障害を急いで直す作業と、不具合になる前に直す作業（予防保守）も、この種類で進める。

| 項目 | 書くこと |
|---|---|
| 最初に示す証拠 | 不具合を再現するテストが、変更の前に落ちることを示す。 |
| 確かめ方 | 再現するテストが変更のあとに通ることと、変えない動きを確かめる既存のテストを書く。 |
| 作業の手順の最初 | 再現するテストを書き、変更の前に落ちることを確かめる。再現できなければ、直す前に人に示す。 |

本番の障害を急いで直す変更は、レビューの深さを「深い」にする（ハーネスの`rules/review.md`の節「レビューの深さ」の緊急の変更）。
