# 確かめる語は、ハーネスのリポジトリでは止め、導入先では人が禁止にすると答えた語だけを止める

| 項目 | 内容 |
|---|---|
| 状態 | 採った |
| 決めた日 | 2026-11-19 |
| 関わる設計 | [`rules/writing.md`の節「機械で止める規則」](../../rules/writing.md#機械で止める規則)、[`features/harness-folder.md`の節「導入先ごとの語の一覧」](../../.harness/docs/features/harness-folder.md#導入先ごとの語の一覧) |
| 語の意味 | [`.harness/docs/ubiquitous-language.md`](../../.harness/docs/ubiquitous-language.md) |

## 背景

確かめる語は、人が指摘した語のうち、正しい使い方もある語で、導入先の業務の言葉（例：契約、不動産の用語）と重なることがある。ハーネスのリポジトリでは、ルールとスキルの文体が導入先の成果物に移るので、確かめる語を止める。

## 判断

語を、どこでも止める語、ハーネスのリポジトリでだけ止める語、導入先で禁止にするかを聞く語、導入先で止める語の4つに分ける。1つ目は止める語で、後ろの3つは、確かめる語を導入先の答え（禁止にしない、無い、禁止にする）で分ける。4つ目には、導入先ごとの語の一覧の`banned`の語も入る。

## 案

### 導入先での確かめる語の扱い

| 案 | 結果 | 理由 |
|---|---|---|
| 導入先ごとに、人が禁止にすると答えた語だけを止める | 採った | 業務の言葉と重なる語だけを残し、ほかの語は導入先でも止められる。 |
| 導入先でも一律に止める | 採らなかった | 導入先の業務の言葉と表記の決めを、言い換えさせる。 |
| 導入先では示すだけにする | 採らなかった | 業務の言葉に当たらない語も、エージェントが書き続けられる。 |

### 導入のときの聞き方

| 案 | 結果 | 理由 |
|---|---|---|
| 導入先での使われ方を探し、使われた場所と勧めを添えた語ごとの表を、1回示す | 採った | 人は表を直して1回で決められ、業務の言葉と重なる語だけを残せる。 |
| すべての語を禁止にするか、しないかの1問にする | 採らなかった | 業務の言葉と重なる語が1つあると、すべてを禁止にしない側を選ぶ。 |
| 導入のときは聞かず、作業の中で語が出たときにだけ聞く | 採らなかった | 決まるまでの間、エージェントが同じ語を書き続ける。 |

### 答えの無い語が出たとき

| 案 | 結果 | 理由 |
|---|---|---|
| 作業の区切りでまとめて聞き、答えを導入先ごとの語の一覧に書く | 採った | 作業を止めずに、区切りで1回聞ける。答えた語は2回聞かない。 |
| 示すだけにし、導入の手順をもう一度動かしたときだけ聞く | 採らなかった | 決める場面が来ないまま残る。 |
| 決まるまで止める | 採らなかった | 業務の言葉でも、作業が止まる。 |

## 結果と失うもの

導入のときの問いが1つ増え、作業の区切りでも語を聞くことがある。答えの無い語は、次の区切りでまた聞く。

## 見直す条件

導入先で、作業の区切りごとに聞く語が減らず、人の手間になったときに見直す。
